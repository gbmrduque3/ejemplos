# ejemplos

## Analog.py
Se configuró el pin 39 del potenciómetro con el propósito de que muestre valores de 0 a 4095 para que cuando se moviera, mostrara los números pantalla continuamente cambiando cada 0,1 segundos.

## leds.py
Se configuró los pines 12, 13, 18, 19, con un led cada uno para que el primer led se encendiera y se apagara por 1 segundo, luego el segundo se encendiera y se apague por 1 segundo y el mismo proceso se repite con el tercer y cuarto led (pines 18 y 19). 

## libmotor.py
Se creo una librería donde se configuró todos los movimientos de los motores, adelante, atrás, izquierda, derecha y para que pare.

## motor.py
Se llama a la librería que contiene los movimientos de los motores para hacer que el carro vaya adelante durante 2 segundo y pare.

## oled.py
Se busca el dispositivo I2C,  y muestra un texto en la pantalla del dispositivo que dice “mocosos feos :3”.

## rgbneopixel
hace que tres leds se prendan con colosres especificos cada uno, rojo, verde y azul.
