# ejemplos Doménica
## analog.py 
mide la posición física de un potenciómetro y lo muestra en una lectura digital
## leds.py 
es para probar la funcionalidad de los pines 12, 13, 18 y 19 encendiéndolos y apagándolos momentáneamente 
## libmotor.py 
define los comandos; adelante, parar, derecha, izquierda, atrás se convirtió en librería para que el código principal se viera más limpio
## motor.py 
es el código principal donde se hace que se mueva durante 2 segundos para que luego se detenga
## oled.py controla 
una pantalla lcd para imprimir lo que se quiere mostrar en la pantalla
## rgbneopixel.py 
controla tres leds y asigna un color diferente para cada led
