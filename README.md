# Ejemplos
## leds.py
Enciende los leds que se encuentran en los pines 12, 13, 18 y 19 durante un segundo.

## analog.py
Configura el pin analógico 39 -corresponde al potenciómetro- como entrada para mostrarlo en la consola cada 0.1 segundos.

## libmotor.py
Crea una librería con la configuración del movimiento que realizarán los motores para ir hacia adelante, atrás, derecha, izquierda y detenerse.

## motor.py
Adjuntamos a libmotor.py para controlar el tiempo y dirección que deseamos que realicen los motores.

## oled.py
Muestra el texto ("Mocosos feos" y una línea abajo ":3") en una pantalla OLED que se encuentra conectada por I2C en la placa ESP32. 

## rgbneopixel.py
Les asigna un color diferente y enciende los 3 leds neopixel que se encuentra en la placa ESP32.
